# cAIge Labs

The lab guides in [`labs/`](labs/) are published on the site at [caige.org/labs](https://caige.org/labs). There is one guide per domain, and each section of the training has a matching task.

## How the labs work today

You run the labs against your own **practice system**. This is a small AI application you build in a sandbox, using only fake data. [Lab 1](labs/lab-1-map-the-system.md) describes the minimum: a retrieval-backed assistant with a few tools, two test tenants, and logging. Every later lab adds controls to that system and measures them.

## Status of the reference application

A shared, deliberately vulnerable reference application ("Acme Support"), with public scoring suites, is planned but **not yet available**. When it ships, the lab guides will be updated so that everyone works against the same system with the same measurements. The cAIge Professional exam will use that application with private suites.
