# cAIge Associate

The cAIge Associate credential shows that a candidate understands AI guardrail engineering. They can:

- explain how AI systems fail;
- classify risks as safety, security, or containment;
- choose appropriate controls and know their limits;
- read evaluation results correctly.

## Format

| Parameter | Detail |
|---|---|
| Questions | 75 scored: multiple choice, multiple select, and scenario-based |
| Time | 120 minutes |
| Coverage | All seven domains, weighted per the [exam blueprint](/training/exam-blueprint) |
| Preparation | The free [training](/training/overview), [labs](/labs), and [practice exam](/practice-exam) |

## Status

**The proctored Associate exam is in development.** The free [practice exam](/practice-exam) is available now and uses the same blueprint. It is self-administered, so it does not award the credential.

Before the proctored exam launches, it needs:

1. a larger question pool, so that each exam form draws from at least three times the number of questions it uses;
2. a beta pilot with real candidates, with item statistics used to retire weak questions;
3. a standard-setting study to set the cut score;
4. a proctoring partner.

Credential verification is already built. Each credential will be signed, and anyone can check it on the [verification page](/verify).

## Recertification

Credentials are valid for two years. The field changes quickly, so recertification follows the current blueprint version.
